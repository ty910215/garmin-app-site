# 铁人三项AI教练 · 公开网站 + 隐私政策页

本目录用于满足 Garmin Connect Developer Program（Startup 档）申请表单中的
「公司网站」与「隐私政策链接」两项硬性要求。

## 文件
- `index.html` — 极简项目介绍页（非商业个人训练系统）
- `privacy.html` — 隐私政策页

## 部署到 GitHub Pages（拿可填表的公开链接）

1. 在 GitHub 新建一个**公开**仓库，例如 `irontri-ai-coach-site`。
2. 把本目录两个 html 文件推送到仓库根目录（保持 `index.html` 与 `privacy.html` 同名）。
3. 仓库 → **Settings → Pages** → Source 选 `main` 分支 `/root`，保存。
4. 等待 1–2 分钟，得到：
   - 网站：`https://<你的用户名>.github.io/irontri-ai-coach-site/`
   - 隐私政策：`https://<你的用户名>.github.io/irontri-ai-coach-site/privacy.html`

> 也可托管到任意静态服务（Vercel / 腾讯云静态网站 / Netlify），只要是两个
> 公网可访问的 https 链接即可。

## 填表时对应
- 表单「公司网站」→ 上面的网站链接
- 表单「隐私政策链接」→ 上面的 privacy.html 链接
- 表单「公司/组织名称」→ `铁人三项AI教练`
