铁人三项AI教练

个人训练闭环系统 · 非商业

项目简介

「铁人三项AI教练」是一个个人使用的训练数据闭环系统，由本人独立开发并仅服务于开发者自身的铁人三项与力量训练管理。系统读取本人运动手表与健康 App 的数据，结合训练科学与个人状态，生成并推送训练计划，再读回实际执行数据做效果评估与下周调整。

本项目不面向公众、不提供注册、不收集任何第三方用户数据，不属于商业产品。

核心功能

  • 健康感知：读取本人 Garmin 睡眠、HRV、静息心率等健康数据，推算训练准备度。
  • 计划生成：依据状态与周期目标，生成力量训练与有氧训练计划。
  • 计划下发：力量训练写入训记 App 记录；有氧训练通过 Garmin Training / Courses API 推送至本人手表引导执行。
  • 结果评估：训练后读回 Garmin 活动与训记实际记录，评估完成度并生成下周调整建议。
  • 营养追踪：读取本人训记营养摄入记录，参与达标判断。

数据来源

Garmin Connect（健康 / 活动） Garmin Training / Courses（推送计划） 训记 Xunji（训练 / 营养）

所有数据均来自开发者本人账户，经本人显式授权后读取与写入，不涉及任何其他个人。

非商业声明

本项目为开发者个人训练辅助工具，不收费、不广告、不对外提供服务。Garmin Connect API 与训记 Open API 仅用于本人数据的读取与回写，符合各平台个人/非商业使用范畴。详见 隐私政策。
